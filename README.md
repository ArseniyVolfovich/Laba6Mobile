# RaceHub — лабораторная работа № 5

Тема: вёрстка мобильно-ориентированного приложения.

## Запуск

Откройте `index.html` для просмотра исходной версии или `dist/index.html` для
просмотра минифицированной сборки. Обе версии работают как статический сайт.

Чтобы пересобрать проект после изменений:

```sh
npm ci
npm run build
```

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| Не менее трёх логических экранов | Вход, главная, события, пилоты, команды, настройки, профиль |
| Структура папок | `css/`, `js/`, `assets/`, `scripts/`, `dist/` |
| Viewport | Точное значение из условия в `index.html` |
| Сброс стилей | Отдельный `css/reset.css` |
| Семантика | `header`, `main`, `nav`, `section`, `footer` |
| Адаптивная сетка на Flexbox | Календарь, личный зачёт, команды, настройки и навигация |
| Относительные размеры | `rem`, `%`, `vw`, `vh` и `calc()` |
| Mobile First | Базовые стили для смартфона без запроса по ширине |
| Расширения для больших экранов | `min-width: 768px` и `min-width: 1024px` |
| Минификация | Команда сборки создаёт HTML, объединённый CSS и JS в `dist/` |

## Организация кода

- `index.html` — экраны приложения, иконки, мобильная навигация.
- `css/reset.css` — небольшой читаемый набор общих правил и сброс стилей.
- `css/style.css` — основное оформление и адаптивные стили приложения.
- `css/min.css` — минифицированная версия `reset.css` и `style.css`, создаваемая сборкой.
- `dist/index.html` — минифицированная разметка.
- `dist/css/style.css` — минифицированные стили, включая reset.
- `dist/js/app.js` — минифицированный JavaScript.
- `js/app.js` — навигация, переключение дисциплин, данные и таймер.
- `scripts/build.cjs` — минификация и копирование изображений.

В исходниках сохраняется удобное форматирование. В `dist/` находятся
сжатые файлы для сдачи или публикации. После правок исходников сборку нужно повторить.

В рабочем `index.html` подключены `reset.css` и `style.css`.
В `dist/index.html` подключены минифицированные `css/style.css` и `js/app.js`.
Сброс стилей уже включён в CSS сборки.
